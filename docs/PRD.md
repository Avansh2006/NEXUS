# NEXUS
Network Exploration & eXtraction for Unified Intelligence Systems.

An investigator brings fragmented synthetic FIRs, call records, and transactions
into one evidence-linked network. Three apparently unrelated cases connect through
a shared phone and account, with human-readable explanations of the connections.

## Must ship
Validated ingestion with row errors and deduplication; deterministic extraction;
conservative resolution; evidence-linked graph; reproducible metrics; R1–R6;
service-identifier suppression; graph workspace; resettable demo.
Every screen displays **PROTOTYPE — SYNTHETIC DATA**.
Alerts are descriptive leads for human review, never determinations of guilt.

## Additional scope
Timeline, reviewable/reversible name matches, printable report, paths, gold-set
extraction evaluation. Authentication/roles and PDF rendering are lower priority.

## Acceptance
Clean reset → load raw seeded records → separate case islands → analyze → shared
nodes and explainable leads → inspect supporting source → generate report.
The runtime demo makes no external API calls. Builds may download dependencies.
No government, telecom, banking integration, prediction, or enforcement.
